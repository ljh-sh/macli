# Design principles

1. **Native first.** Use Apple frameworks directly instead of wrapping shell tools.
2. **AI friendly.** JSON/TSV output, predictable schemas, minimal context.
3. **Small surface.** One binary, focused subcommands, no GUI.
4. **Reproducible.** Deterministic builds with pinned toolchains and timestamps.
5. **Reviewed.** Every `main` branch change goes through a code-owner review.
