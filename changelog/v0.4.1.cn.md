## 新增

- 新增 npm 包 `@ljh-sh/macli`。
  - 在 `npm install` 时从 GitHub release 下载 `macli-darwin-universal.tar.xz` 二进制。
  - 通过 `npm install -g @ljh-sh/macli` 全局安装 `macli` 命令。
- 新增 `.github/workflows/npm.yml`，在每个 `v*` tag 推送时自动发布 npm 包。
- 在 `README.md`、`README.cn.md` 和 `docs/install.md` 中补充 npm 安装说明。

## 说明

- 该 npm 包仅支持 macOS；在其他平台安装时会跳过二进制下载并提示。
- 发布工作流需要仓库配置 `NPM_TOKEN` secret。
