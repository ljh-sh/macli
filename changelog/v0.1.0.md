## Highlight

- Remove `notify` subcommand entirely (`NSUserNotification` is deprecated and
  `schedule` cannot survive process exit).
- Parser now rejects missing values and supports `--opt=value` to disambiguate
  `--foo --bar`.
- `monitor` aligns samples by position, validates `--interval`/`--count`, and
  handles SIGINT/SIGTERM without losing the final line.
- Destructive `rm` commands require `--yes`.

## Add

- `cal rm --type event|reminder` so only the required TCC permission is requested.
- `--yes` confirmation flag for `cal rm`, `event rm`, and `reminder rm`.
- Guard against nil dates in `event ls --week` and `--month`.
- Parser support for `--option=value` syntax.

## Fix

- Dead ternary and silent parse failures in `Cmd.swift`.
- `monitor` signal handlers now flush the last sample before exiting.
- `monitor` name-collision risk by aligning samples positionally.
- `cal rm` over-requesting Reminders permission for event-only calendars.
- Codeberg mirror workflow for tag pushes (`HEAD:main` instead of `main`).

## Remove

- `notify send` and `notify schedule` subcommands. Use
  `osascript -e 'display notification ...'` instead.

## Change

- GitHub Actions dependency bumps via Dependabot.
- Homebrew tap renamed to `ljh-sh/homebrew-cli`.

## Note

- Breaking change: scripts using `macli notify` need to migrate to `osascript`.
- Breaking change: `cal rm`, `event rm`, and `reminder rm` now require `--yes`.
- Release assets are signed with cosign `.sigstore.json` bundles.
