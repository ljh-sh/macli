# macli v0.5.0

## Battery

- `macli battery` now exposes ~150 fields from `AppleSmartBattery`, making it a strict superset of `ioreg -n AppleSmartBattery -r` for useful data.
- Decode previously-opaque binary blobs:
  - `raTableRaw` per-cell resistance tables
  - `batteryStateBytes`
  - `charger.statusBytes`
  - `mfgDataAscii` / `manufacturerDataAscii`
- Add derived metrics: `cellVoltageDelta`, `estimatedFullChargeWh`, `instantPowerWatts`, `charger.powerWatts`.
- Output `iMaxAndSocSmoothTable` as hex.
- Fix unsigned accumulator handling for fields like `PassedCharge`, `PackCurrentAccumulator`, `AccumulatedBatteryDischarge`.
- Add docs: comprehensive field reference, diagnostics cookbook, charging control guide, battery care & myths.

## Docs

- Rewrite README battery section with highlights and 10 scripting examples.
- Add `docs/battery.md`: field reference, binary decoding, control tool comparison, care guide.

## Other

- No breaking changes to existing `macli battery` keys.
