## Highlight

- First public release of `macli`.
- Native Apple framework only — no Python runtime, no osascript overhead, no GUI.
- AI-friendly output schema: `{"ok": true, ...}` on success, `{"ok": false, "error": ..., "hint": ...}` on failure.

## Add

- `macli smc` — read Apple Silicon HID sensor (temperature / voltage / current).
- `macli smc86` — Intel SMC legacy path (sunset track).
- `macli monitor` — stream sensor sample as TSV for shell pipeline.
- `macli cal / event / reminder` — EventKit calendar / event / reminder access.
- `macli notify` — send macOS notification from script.
- Install option: Homebrew tap, direct binary tarball, and `x eget`.

## Note

- macOS-only (macOS 12+ / Swift 5.10+).
- Release asset includes `macli-darwin-arm64.tar.xz`, `macli-darwin-x64.tar.xz`, `macli-darwin-universal.tar.xz`, plus `SHA256SUMS` and `BUILD_INFO.txt`.
