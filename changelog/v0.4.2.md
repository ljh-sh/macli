# macli v0.4.2

## Packaging

- Fix npm postinstall script to use Node.js built-in `fetch` instead of relying on a system `curl` binary.
- This makes `npm install -g @ljh-sh/macli` work on macOS systems where `curl` is a shim or unavailable.
- SHA256 checksums from the GitHub release are verified after download.

No functional CLI changes.
