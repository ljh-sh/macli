## Highlight

- `macli display brightness` reads the current brightness of all online
  displays as a JSON or TSV snapshot.
- `macli display brightness --set 0.5` sets the built-in display brightness
  to the requested 0.0–1.0 level using `DisplayServices`.
- `macli gpu info` reports the active GPU name, unified-memory availability,
  recommended working-set size, and `IOKit` `gpu-core-count`.
- `macli monitor --metrics gpu_metrics` streams device/tiler/renderer
  utilization and in-use/allocated system memory from `AGXAccelerator`
  `PerformanceStatistics`.

## Add

- `macli display` top-level command with `list` and `brightness` subcommands.
- `DisplayCtrl` backed by `DisplayServices.framework` (loaded dynamically).
- `macli gpu` top-level command with `info` subcommand.
- `GpuCtrl` combining `Metal` device info and `IOKit` `AGXAccelerator` properties.
- `GpuMetricsCtrl` + `GpuMetricsSource` for monitor integration.
- `--metrics gpu_metrics` in `macli monitor`.

## Change

- `Package.swift` links the `macli` executable against `Metal`, `IOKit`, and
  `CoreGraphics`.

## Note

- Display brightness set requires an Apple-controlled adjustable display
  (typically the built-in display). External monitors that do not support
  `DisplayServices` brightness control will report an error instead of being
  modified.
- GPU utilization metrics are experimental: counter key names and availability
  vary across Apple Silicon generations. Values may be absent on unsupported
  hardware.
