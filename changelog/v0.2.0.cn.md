## 亮点

- `macli battery` 现在返回完整的 AppleSmartBattery 快照：循环次数、
  设计/最大/当前容量、健康百分比、电芯电压、Qmax、设计/当前 Wh、
  输入/系统/电池功耗、温度、充电器信息、生产日期和序列号。
- 输出模式：`--json`（默认）、`--tsv`、`--plist`（原始 IORegistry 快照，
  XML 属性列表）。
- `macli monitor --metrics battery_power` 可流式监控电池功耗。
- 解析器正确性由模拟 IORegistry 数据测试覆盖，可在 GitHub Actions 运行。

## 新增

- 顶层命令 `macli battery`，支持 `--json`、`--tsv`、`--plist`。
- 顶层命令 `macli ssd`，用于查看 NVMe 硬盘信息与 SMART 状态。
- 可执行测试目标 `batteryTests`，使用模拟的 `AppleSmartBattery` 数据。
- `macli monitor` 的 `battery_power` 指标源。
- 通用 XML plist 序列化辅助 `XCMD.plist.data()`。

## 修复

- `macli smc all` 现在包含真实的 IOKit 电池与功耗字典，
  而不是占位提示和空数组。

## 说明

- `--plist` 基于 Foundation 的 `PropertyListSerialization` 实现，
  不会额外增加二进制体积。
- macOS 未公开 SSD 磨损百分比；如需详细 SMART 磨损数据请使用 `smartctl`。
