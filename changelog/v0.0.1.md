## Highlight

- GitHub releases are now signed with cosign keyless `.sigstore.json` bundles.
- OpenSSF Scorecard workflow and badge added.
- `speech recognize` and `speak` subcommands removed.
- README restructured around SMC sensors, streaming monitor, and EventKit.

## Add

- `SECURITY.md`, `.github/dependabot.yml`, and hardened CI / CodeQL / Scorecard workflows.
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `ROADMAP.md`, and GitHub issue/PR templates.
- Codeberg mirror workflow for `main` and tags.
- OpenSSF Scorecard badge and CI badge in README.

## Change

- README rewritten as a pyramid: at-a-glance examples + grouped FAQ.
- FAQ reorganized with category headings and emoji question titles.
- AI-agent prompt now bootstraps install (`brew install ljh-sh/cli/macli`).

## Remove

- `speech recognize` and `speak` subcommands. Both need a bundled `.app` with a
  proper bundle identifier for TCC, which conflicts with the CLI-only design.

## Fix

- Cosign release signing switched to bundle format recognized by OpenSSF Scorecard.
- Codeberg mirror trigger syntax for tags.

## Note

- Release assets include `macli-darwin-*.tar.xz`, `SHA256SUMS`, `BUILD_INFO.txt`,
  plus cosign `.sigstore.json` signature bundles.
