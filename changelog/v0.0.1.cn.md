## Highlight

- GitHub Release 资产使用 cosign keyless `.sigstore.json` bundle 签名。
- 新增 OpenSSF Scorecard workflow 与徽章。
- 移除 `speech recognize` 和 `speak` 子命令。
- README 围绕 SMC 传感器、流式 monitor 和 EventKit 重新组织。

## Add

- `SECURITY.md`、`.github/dependabot.yml` 以及加固后的 CI / CodeQL / Scorecard workflow。
- `CONTRIBUTING.md`、`CODE_OF_CONDUCT.md`、`ROADMAP.md` 和 GitHub issue/PR 模板。
- Codeberg mirror workflow，同步 `main` 与 tags。
- README 中的 OpenSSF Scorecard 与 CI 徽章。

## Change

- README 改为金字塔结构：一览示例 + 分类 FAQ。
- FAQ 按分类标题和 emoji 问题标题重新组织。
- AI agent prompt 现在自带安装引导（`brew install ljh-sh/cli/macli`）。

## Remove

- `speech recognize` 和 `speak` 子命令。二者都需要带有 bundle identifier 的
  bundled `.app` 才能通过 TCC，与 CLI-only 设计冲突。

## Fix

- cosign 发布签名改为 OpenSSF Scorecard 可识别的 bundle 格式。
- Codeberg mirror 对 tags 的触发语法。

## Note

- Release 资产包括 `macli-darwin-*.tar.xz`、`SHA256SUMS`、`BUILD_INFO.txt`，
  以及对应的 cosign `.sigstore.json` 签名 bundle。
