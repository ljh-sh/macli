## Add

- New npm package `@ljh-sh/macli`.
  - Downloads the `macli-darwin-universal.tar.xz` binary from the GitHub release during `npm install`.
  - Installs the `macli` command globally via `npm install -g @ljh-sh/macli`.
- `.github/workflows/npm.yml` to publish the npm package on every `v*` tag push.
- npm install instructions added to `README.md`, `README.cn.md`, and `docs/install.md`.

## Notes

- The npm package is macOS-only; installation on other platforms skips the binary download with a message.
- Requires an `NPM_TOKEN` repository secret for the publish workflow.
