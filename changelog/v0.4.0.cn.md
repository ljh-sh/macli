## 亮点

- `macli display brightness` 以 JSON 或 TSV 快照读取所有在线显示器的当前亮度。
- `macli display brightness --set 0.5` 通过 `DisplayServices` 将内置显示器亮度
  设置为指定的 0.0–1.0 级别。
- `macli gpu info` 报告当前 GPU 名称、是否使用统一内存、推荐工作集大小以及
  `IOKit` 的 `gpu-core-count`。
- `macli monitor --metrics gpu_metrics` 从 `AGXAccelerator` 的
  `PerformanceStatistics` 流式输出设备/tiler/renderer 利用率以及
  在用/已分配系统内存。

## 新增

- `macli display` 顶层命令，包含 `list` 和 `brightness` 子命令。
- 基于动态加载 `DisplayServices.framework` 的 `DisplayCtrl`。
- `macli gpu` 顶层命令，包含 `info` 子命令。
- 结合 `Metal` 设备信息与 `IOKit` `AGXAccelerator` 属性的 `GpuCtrl`。
- 用于 `monitor` 集成的 `GpuMetricsCtrl` 与 `GpuMetricsSource`。
- `macli monitor --metrics gpu_metrics`。

## 变更

- `Package.swift` 将 `macli` 可执行目标链接到 `Metal`、`IOKit` 与 `CoreGraphics`。

## 注意

- 设置显示器亮度需要 Apple 可控的可调亮度显示器（通常是内置显示器）。
  不支持 `DisplayServices` 亮度控制的外接显示器会返回错误，不会被修改。
- GPU 利用率指标为实验性：计数器键名与可用性在不同 Apple Silicon 代际之间
  可能不同。不受支持的硬件上可能缺失相应数值。
