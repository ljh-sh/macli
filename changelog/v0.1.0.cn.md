## Highlight

- 完全移除 `notify` 子命令（`NSUserNotification` 已废弃，且 `schedule` 无法在进程
  退出后继续生效）。
- 解析器现在会拒绝缺失值，并支持 `--opt=value` 以消除 `--foo --bar` 歧义。
- `monitor` 改为按位置对齐样本，校验 `--interval` / `--count`，并在 SIGINT / SIGTERM
  时保证最后一行被 flush。
- 破坏性 `rm` 命令需要 `--yes` 确认。

## Add

- `cal rm --type event|reminder`，仅请求所需的 TCC 权限。
- `cal rm`、`event rm`、`reminder rm` 的 `--yes` 确认 flag。
- `event ls --week` / `--month` 对 nil 日期的保护。
- 解析器支持 `--option=value` 语法。

## Fix

- `Cmd.swift` 中的死三元与静默解析失败。
- `monitor` 信号处理现在会在退出前 flush 最后一个样本。
- `monitor` 同名传感器覆盖风险，改为按位置对齐。
- `cal rm` 对纯事件日历过度请求 Reminders 权限的问题。
- Codeberg mirror workflow 对 tag push 的处理（改为 `HEAD:main`）。

## Remove

- `notify send` 和 `notify schedule` 子命令。请改用
  `osascript -e 'display notification ...'`。

## Change

- Dependabot 升级的 GitHub Actions 依赖版本。
- Homebrew tap 改名为 `ljh-sh/homebrew-cli`。

## Note

- Breaking change：使用 `macli notify` 的脚本需要迁移到 `osascript`。
- Breaking change：`cal rm`、`event rm`、`reminder rm` 现在需要 `--yes`。
- Release 资产使用 cosign `.sigstore.json` bundle 签名。
