## Highlight

- `macli battery` now returns a full AppleSmartBattery snapshot:
  cycle count, design/max/current capacity, health percentage, cell voltages,
  Qmax, design/current Wh, input/system/battery power, temperature, charger
  info, manufacture date and serial numbers.
- Output modes: `--json` (default), `--tsv`, and `--plist` (raw IORegistry
  snapshot as XML property list).
- Battery power metrics are available in `macli monitor --metrics battery_power`.
- Parser correctness is validated by mocked IORegistry tests that run on
  GitHub Actions runners.

## Add

- `macli battery` top-level command with `--json`, `--tsv`, `--plist`.
- `macli ssd` top-level command for NVMe drive info and SMART status.
- `batteryTests` executable target using mocked `AppleSmartBattery` data.
- `battery_power` metric source for `macli monitor`.
- Generic `XCMD.plist.data()` helper for XML plist serialization.

## Fix

- `macli smc all` now includes the real IOKit battery and power dictionaries
  instead of a placeholder note and empty array.

## Note

- `--plist` uses Foundation's `PropertyListSerialization`; no extra binary
  size cost beyond a small output-branch in the executable.
- SSD wear percentage is not exposed by macOS; use `smartctl` for detailed
  SMART wear-level data.
