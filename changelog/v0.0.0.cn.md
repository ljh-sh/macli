## 亮点

- macli 首次公开发布。
- 仅使用原生 Apple framework，无 Python runtime、无 osascript 开销、无 GUI。
- AI 友好输出 schema：成功返回 `{"ok": true, ...}`，失败返回 `{"ok": false, "error": ..., "hint": ...}`。

## 新增

- `macli smc` — 读取 Apple Silicon HID 传感器（温度 / 电压 / 电流）。
- `macli smc86` — Intel SMC 兼容路径（sunset track）。
- `macli monitor` — 以 TSV 流式输出传感器样本，供 shell 管道处理。
- `macli cal / event / reminder` — EventKit 日历 / 事件 / 提醒访问。
- `macli notify` — 从脚本发送 macOS 通知。
- 安装方式：Homebrew tap、直接下载二进制 tarball、`x eget`。

## 注意

- 仅支持 macOS（macOS 12+ / Swift 5.10+）。
- Release asset 包含 `macli-darwin-arm64.tar.xz`、`macli-darwin-x64.tar.xz`、`macli-darwin-universal.tar.xz`，以及 `SHA256SUMS` 和 `BUILD_INFO.txt`。
