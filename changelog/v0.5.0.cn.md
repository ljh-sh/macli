# macli v0.5.0

## Battery

- `macli battery` 现在暴露约 150 个字段，是 `ioreg -n AppleSmartBattery -r` 的严格超集。
- 解码二进制 blob：`raTableRaw`、`batteryStateBytes`、`charger.statusBytes`、`mfgDataAscii`、`manufacturerDataAscii`。
- 新增派生指标：`cellVoltageDelta`、`estimatedFullChargeWh`、`instantPowerWatts`、`charger.powerWatts`。
- 输出 `iMaxAndSocSmoothTable` hex。
- 修复无符号累加器被解释为有符号导致变负数的问题。
- 新增完整文档：字段参考、诊断脚本、充电控制指南、电池保养与误区。

## Docs

- 重写 README 电池章节，含 Highlights 和 10 个诊断脚本示例。
- 新增 `docs/battery.md`：字段速查、二进制解码、控制工具对比、保养决策。
